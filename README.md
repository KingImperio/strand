# Strand

A personal link hub. One page, every way to find you.

## What it does
Strand is a single-page link hub. It loads a profile avatar, a short bio, and a vertical list of links to the places you live online. It is built for personal use: drop in your own links array and host it on any static host. No build step, no framework, no server.

## Tech
- HTML / CSS / JavaScript (Vanilla)
- Fontshare CDN (Satoshi + Recoleta)
- Inline SVG icons and noise texture

## Run locally
Download or clone the repo. Open index.html in a browser. No build step required.
